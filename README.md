# 📰 Телеграм-бот-агрегатор новостей

[![Java](https://img.shields.io/badge/Java-17-orange.svg)](https://openjdk.java.net/projects/jdk/17/)
[![Maven](https://img.shields.io/badge/Maven-3.8+-blue.svg)](https://maven.apache.org/)
[![JUnit 5](https://img.shields.io/badge/Tests-JUnit%205-green.svg)](https://junit.org/junit5/)

Современный автоматизированный агрегатор новостей с удобным интерфейсом телеграм-бота, предназначенный для сбора, категоризации и анализа новостей из различных российских источников.

## 🌟 Основные возможности

- **Мультиагрегация источников**: собирает новости с ведущих российских ресурсов, таких как **РИА**, **Rambler** и **Mail.ru**.
- **Умная категоризация**: автоматически классифицирует новости по 15 различным категориям (например, политика, экономика, технологии).
- **AI-резюме**: генерирует краткие сводки новостей с помощью **DeepSeek API** через OpenRouter.
- **Глубокая аналитика**: предоставляет статистику по распределению новостей, выявляет тренды и отслеживает упоминания публичных персон.
- **Расширенный поиск**: позволяет искать новости по ключевым словам и фразам.
- **Плановые обновления**: автоматически получает свежие новости по настраиваемому расписанию.
- **Экспорт данных**: экспортирует новости в различные форматы, включая **CSV**, **JSON** и **HTML**.
- **Интерактивный интерфейс**: удобный телеграм-бот с кнопками и командами для легкой навигации.

## 🛠️ Технологический стек

- **Ядро**: Java 17, Maven
- **База данных**: SQLite
- **Telegram API**: [Java Telegram Bot API](https://github.com/rubenlagus/TelegramBots)
- **Веб-скрапинг**: JSoup
- **Интеграция AI**: OpenRouter API (для DeepSeek)
- **Тестирование**: JUnit 5, Mockito
- **Логирование**: SLF4J

## 🚀 Быстрый старт

### Необходимые компоненты

- Java 17 или выше
- Maven 3.6+
- Токен Telegram-бота (получить у [@BotFather](https://t.me/BotFather))
- Ключ OpenRouter API (для функций AI-резюме)

### Установка и настройка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/java-news-aggregator.git
    cd java-news-aggregator
    ```

2.  **Настройте приложение:**
    Создайте файл `src/main/resources/application.properties` и добавьте следующую конфигурацию. Замените значения на свои реальные данные.

    ```properties
    # Конфигурация Telegram-бота
    bot.token=YOUR_BOT_TOKEN
    bot.username=YOUR_BOT_USERNAME

    # Конфигурация базы данных
    database.path=news.db

    # Конфигурация получения новостей
    news.max.per.request=5
    parsing.interval.minutes=30

    # Конфигурация OpenRouter API
    openrouter.api.key=YOUR_OPENROUTER_API_KEY
    openrouter.api.url=https://openrouter.ai/api/v1/chat/completions
    ```

3.  **(Опционально) Используйте .env для секретов и переменных окружения:**

   Вместо (или вместе с) файла `application.properties` вы можете создать файл `.env` в корне проекта для хранения секретных ключей и переменных окружения. Переменные из `.env` имеют приоритет над значениями из `application.properties`.

   **Пример `.env**:**
   ```env
   BOT_TOKEN=ваш_токен_бота
   BOT_USERNAME=ваш_юзернейм_бота
   OPENROUTER_API_KEY=ваш_ключ_OpenRouter
   OPENROUTER_API_URL=https://openrouter.ai/api/v1/chat/completions
   ```

3.  **Соберите и запустите приложение:**
    ```bash
    # Сборка проекта и запуск тестов
    mvn clean package
    mvn package

    # Запуск приложения
    java -jar target/news-aggregator-1.0.0.jar
    ```
    Ваш бот должен быть запущен и готов к работе в Telegram.

## 🤖 Использование бота

Взаимодействуйте с ботом с помощью команд ниже или через удобные кнопки.

### Справочник команд

| Команда         | Описание                                                                 |
| --------------- | ------------------------------------------------------------------------ |
| `/start`        | Инициализация бота и приветственное сообщение.                           |
| `/help`         | Показать справку со всеми доступными командами.                          |
| `/latest`       | Получить и показать самые свежие новости.                                |
| `/categories`   | Показать меню с категориями новостей для просмотра.                      |
| `/search <term>`| Поиск новостей по заданному термину.                                    |
| `/stats`        | Показать статистику по количеству новостей в каждой категории.           |
| `/trends`       | Показать самые обсуждаемые темы (трендовые теги).                        |
| `/persons`      | Список наиболее часто упоминаемых публичных персон в новостях.           |
| `/summary`      | Сгенерировать и показать AI-резюме последних новостей.                   |
| `/update`       | Вручную запустить получение новых статей со всех источников.              |
| `/export`       | Показать меню экспорта новостей в CSV, JSON или HTML.                    |
| `/activity`     | Сгенерировать график активности новостей за последнюю неделю.            |

## 🏗️ Архитектура

Проект построен по модульному принципу, разделяя логику по пакетам для удобства поддержки и расширения.

```
ru.news/
├── NewsAggregatorApplication.java  # Главная точка входа приложения
├── bot/                           # Логика Telegram-бота
├── config/                        # Конфигурация приложения
├── database/                      # Работа с базой данных (SQLite)
├── exception/                     # Кастомные классы исключений
├── model/                         # Модели данных (News, NewsCategory)
├── parser/                        # Парсеры новостей для разных источников
└── service/                       # Основные сервисы бизнес-логики
```

### Основные сервисы

- **`NewsService`**: Управление жизненным циклом новостей (CRUD-операции).
- **`NewsParsingService`**: Организация парсинга новостей из разных источников.
- **`NewsSchedulerService`**: Планирование периодических задач по получению новостей.
- **`AnalyticsService`**: Анализ данных для трендов и статистики.
- **`TextProcessingService`**: Очистка текста и извлечение сущностей.
- **`AiSummaryService`**: Интерфейс для AI-резюме, с реализацией через `DeepSeek`.
- **`ExportService`**: Логика экспорта данных в различные форматы.

## 🧩 Расширение агрегатора

### Добавление нового источника новостей

Чтобы добавить новый источник, создайте класс, реализующий интерфейс `NewsParser`, и опишите свою логику парсинга.

**Пример:**

```java
// src/main/java/ru/news/parser/NewSourceParser.java
package ru.news.parser;

import ru.news.model.News;
import java.util.List;

public class NewSourceParser implements NewsParser {
    @Override
    public List<News> parseNews() {
        // Ваша логика парсинга и скрапинга
    }

    @Override
    public String getSourceName() {
        return "Название нового источника";
    }
}
```

После создания парсера интегрируйте его в `NewsParsingService`, чтобы он участвовал в регулярном цикле сбора новостей.
